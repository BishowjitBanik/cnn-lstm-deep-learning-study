CNN & LSTM – Deep Learning Study

Project Overview

This project explores two Deep Learning applications:

1. CNN – Age and Gender Estimation: A Convolutional Neural Network (CNN) approach for estimating age and gender from facial images.
2. LSTM – Stock Price Prediction: A Long Short-Term Memory (LSTM) approach for forecasting stock prices.

Project Objectives

* Explore CNN-based image analysis.
* Understand age and gender estimation.
* Apply LSTM for time-series forecasting.
* Understand practical applications of Deep Learning.
